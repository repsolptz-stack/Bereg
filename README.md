# Берег — обновлённый мобильный прототип

Комплект для показа людям, проверки ценности идеи и обсуждения визуального направления.

## Что внутри
- `index.html` — обновлённый интерфейс в тёплой тёмной палитре с плавающей навигацией, быстрой отметкой состояния, дыхательным тренажёром 4-4-6, подсказками по состояниям, таймером паузы на 15 минут, этапами восстановления и списком близкого круга.
- `manifest.json` и `sw.js` — поддержка добавления на главный экран смартфона и базового офлайн-кэширования.

## Как выложить на GitHub Pages
1. Создай репозиторий на GitHub и загрузи в корень `index.html`, `manifest.json`, `sw.js` и `README.md`.
2. Включи GitHub Pages в **Settings → Pages** (ветка `main`, папка `/ (root)`).
3. Открой ссылку на телефоне и добавь ярлык на главный экран.
